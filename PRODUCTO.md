# BETTRACK PRO — Producto de seguimiento financiero

## Estado del producto
Aplicación web responsive de seguimiento de movimientos financieros, con balance, resultados, calendario, gráfico e historial. Funciona sin servidor y almacena información localmente en el navegador.

**Demo:** https://tobarcarrascom-wq.github.io/BETTRACK/

## Funcionalidades actuales verificadas en el código
- Registro de ganancias y pérdidas, fecha y nota.
- Balance total y resultado neto.
- Calendario con saldo acumulado al cierre de cada día.
- Historial y eliminación de movimientos con confirmación.
- Gráfico de evolución.
- Configuración de saldo inicial.
- Exportación e importación de respaldos JSON.
- Diseño responsive en español.

## Limitaciones y condiciones de entrega
- No existe autenticación, sincronización en nube ni base de datos remota.
- Los datos se guardan en el navegador de cada usuario; borrar datos del navegador puede eliminarlos.
- El código de esta versión está alojado en un repositorio público; no se puede prometer exclusividad histórica ni impedir que terceros ya hayan obtenido una copia.
- No hay todavía pruebas automatizadas ni auditoría de seguridad independiente.
- No incluye procesamiento de pagos, apuestas ni transacciones financieras.
